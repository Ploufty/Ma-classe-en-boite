# Ma-classe-en-boite
Ma Classe en Boîte aide les enseignants à gérer leur classe : liste des élèves, groupes, cantine et garderie, anniversaires, pense-bête, et feuilles de présence à imprimer. Tout se fait dans le navigateur, sans compte ni installation.

Mode d'emploi complet : `aide.html` (bouton « 📖 Mode d'emploi » en haut de l'outil), avec le format CSV attendu et un modèle vierge (`modele-classe-vierge.csv`).
